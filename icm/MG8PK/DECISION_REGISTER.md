# NYCH Language Model V1 — Owner Decision Register

Use the Model Builder Decision Console specified in the Grokbot build handoff to review pending decisions. Owner approvals freeze each contract; then independent builders may launch concurrently, with integration still dependency-gated.

## Approved
- Ingest accepts UTF-8 bytes up to 65,536 bytes; it rejects empty, malformed, or oversized input without normalization or truncation.
- Raw prompt text remains in request memory only. Never persist it or include it in QSON. QSON may contain digest and metadata only.
- Candidate builds and independent inspections run in parallel against frozen contracts. Integration is dependency-gated.
- Weight pruning is deferred to Builder Pro V2.
- D0 model objective is approved: deterministic NYCH encoder; tiny decoder-only causal LM; next NYCH token/symbol sequence; symbolic assurance kept distinct from probabilistic output.
- D1-context is approved: 1,024 tokens per window; longer accepted input is split into ordered windows; truncation is never. A later D7 `position_limit` must equal 1024. D7 itself is not approved.
- D5 / B5 GST v2 and the additive TOTE migration 002 are approved and were reconfirmed against the expanded definition: request-scoped GST, schema `nych-language-model/schemas/gst-context-v1.schema.json`, source of truth `nych-language-model/src/nych_language_model/pipeline/gst_context.py`. Migration of an existing SQLite database and TOTE conformance tests remain deferred.
- GitHub repositories were created private; public release is not implied.
