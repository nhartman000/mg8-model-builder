# Domain from objects — design note, not behavior

This note records an owner statement. It does not add domain inference, a relatedness score, or a tag emitter.

Owner statement, verbatim, 2026-11-10 at 9:59 PM ET. Stated, not approved: "domain is made more obvious by objects discussed. objects preclude to an action that is coupled with industry. Objects not obviously related to the domain at hand assumes a domain or ssubject change".

Interpretation, flagged as interpretation and not owner-stated: domain is inferred from the objects under discussion; objects lead to an action tied to an industry or domain; an object not obviously related to the current domain implies a domain or subject change.

No code infers a domain from objects. These owner questions stay open:

- How "not obviously related" is measured, including any threshold and the source of an object-to-domain mapping.
- Whether an inferred change must emit a `dom>` tag.
- How an inferred change interacts with the explicit `dom>?<domain>` ... `?=N` tags.
